# 第2フェーズ: ファミコンパレット減色変換ツール

任意の画像（写真・イラスト・用意済みのディザ画像）を、ファミコンの表示制約に合わせて減色し、
第1フェーズの仕組み（ROM + bridge.lua）を使ってエミュレータにリアルタイム表示する。

方針（PLAN.md のリスク対策）: **ディザ画像をあらかじめ用意し、できるだけ違和感を抑えるまでにとどめる。**
→ GUI で設定を詰めて見え方を確認し、一括変換ツールで事前に変換・保存しておく使い方を想定。

---

cd D:\hobby\nes\project

## 2. エミュレータにリアルタイム表示する

第1フェーズと同じく PowerShell を2つ使う。**お絵描きツール（run_paint.ps1）は閉じておく**
（両方が同じ state.bin に書き込むため）。

1. 減色変換ツールを起動

```powershell
.\run_convert.ps1
```

2. LuaNES をブリッジ付きで起動

```powershell
.\run_luanes.ps1
```

3. 変換ツールで「ファイル → 画像を開く」（Ctrl+O）、またはコピーした画像を **Ctrl+V** で貼り付ける。
   変換結果がすぐエミュレータに表示される。スライダーを動かすと約 0.15 秒後に再変換・再送信される。

起動と同時に画像を開くこともできる:

```powershell
.\run_convert.ps1 D:\path\to\photo.jpg
```

### 2.1 画面の見方
- 左: 元画像を 128×120 に整えたもの（調整後）
- 右: 変換後。ファミコンでの実際の見え方
- 下: 選ばれたパレット（P0〜P3。左端は共通背景色）
- ステータスバー: 変換時間、**平均色差 ΔE**（小さいほど元画像に近い。目安: 10 以下ならかなり近い）

### 2.2 設定項目

| 項目 | 内容 | おすすめ |
|---|---|---|
| 配置 | 全体を収める（余白あり）/ 画面を埋める（はみ出しを切る）/ 引き伸ばす | 写真は「画面を埋める」 |
| 縮小方法 | なめらか / 平均 / ニアレスト | **用意済みのディザ画像・ドット絵は「ニアレスト」**（ドットが崩れない） |
| 明るさ・コントラスト・彩度・ガンマ・シャープ | 変換前の画質調整 | ファミコンの色は鮮やかなので、彩度を少し上げると合いやすい |
| ディザ | なし / パターン（Bayer 8×8）/ 誤差拡散（Floyd–Steinberg） | 写真は誤差拡散、イラストはなし、グラデーションはパターン |
| ディザの強さ | 0〜1 | 0.6〜0.8。強すぎるとザラつく |
| 色の比べ方 | Lab（見た目重視）/ RGB | Lab |
| 背景色 | 自動 / 固定（16進で入力して Enter） | 黒背景にしたいときは固定 `0F` |
| 品質 | 試す背景色の候補数（1〜8） | 4。上げると良くなることがあるが遅い |
| 元画像ファイルの変更を監視 | 別のペイントソフトで画像を保存すると自動で再変換・再送信 | ディザ画像を手作業で用意するときに便利 |

### 2.3 保存（ファイルメニュー）
| メニュー | 出力 | 用途 |
|---|---|---|
| お絵描きツール用に保存 | `.npaint.json` | `run_paint.ps1` のお絵描きツールで開いて、気になる点を手で直せる |
| プレビュー画像を保存 | `.png` | 見た目の記録・比較 |
| ファミコン用データ書き出し | `_chr.bin` / `_attr.bin` / `_pal.bin` | 第3フェーズで ROM に埋め込む |

## 3. 事前変換（一括変換）

フォルダ内の画像をまとめて変換し、一覧ページ（index.html）を作る。

```powershell
.\run_batch.ps1 D:\path\to\images
```

ディザ3種類（なし / パターン / 誤差拡散）を書き出して見比べる:

```powershell
.\run_batch.ps1 D:\path\to\photo.jpg --compare
```

用意済みのディザ画像を、ドットを崩さずに変換する:

```powershell
.\run_batch.ps1 D:\path\to\dithered --resample nearest --dither none
```

出力先は既定で `build\converted\`（`-o` で変更）。`index.html` をブラウザで開くと、元画像と変換結果が並ぶ。
オプション一覧は `.\run_batch.ps1 --help`。

## 4. 仕組み

```
画像 ─(1)─> 128×120 に整える・画質調整
     ─(2)─> 各画素とファミコン色（約52色）の距離を Lab で計算
     ─(3)─> 背景色の候補ごとに「4パレットの色選び」と「16×16 ブロックへのパレット割り当て」を交互に最適化
     ─(4)─> 各ブロックの4色だけでディザリング
     ─(5)─> 第1フェーズの Picture 形式 → state.bin → bridge.lua → ROM → 画面
```

| ファイル | 内容 |
|---|---|
| `tools/converter/nes_convert.py` | 変換エンジン（GUI なしでも使える。将来サーバー側変換にも流用可） |
| `tools/converter/convert_gui.py` | GUI（変換は別スレッドで実行し、画面が固まらないようにしている） |
| `tools/converter/batch_convert.py` | 一括変換 CLI |
| `run_convert.ps1` / `run_batch.ps1` | 起動スクリプト |
| `requirements.txt` | 必要な Python ライブラリ |

### 制約メモ
- 出力サイズは第1フェーズの ROM に合わせて **128×120**。全画面（256×240）は第4フェーズで対応する
- $0D（黒より黒い色）は使わない。黒は $0F に統一
- 16×16 ブロックの境目で色が変わって見える（ファミコンの属性の制約）。「属性グリッドを表示」で確認できる。
  気になる場所はお絵描きツールで手直しする
